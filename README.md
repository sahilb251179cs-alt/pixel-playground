# NO VACANCY: Grand Arcadia

A large, asset-free browser horror game set in a deserted hotel. The hotel is generated in Canvas and has 48 guest rooms, a central lobby, furniture, a roaming monster, hidden room keys, story clues, and a four-digit front-door puzzle.

## Play

Open `index.html` in a desktop or mobile browser and select **Check In**.

| Action | Desktop | Touch screen |
| --- | --- | --- |
| Move | W/A/S/D or WASD | Left virtual stick |
| Look | Mouse; arrow keys turn | Drag on the game view |
| Interact | E | Use button |
| Flashlight | F | Light button |
| Run / crouch | Shift / C | Run / Crouch buttons |

Search the guest rooms for five keys. Find the Room 312 housekeeping note to learn the code, then return to the lobby doors. Read the other hotel records and restore the lobby transmitter to uncover alternate endings. The over-the-shoulder view keeps your character visible. Crouch to make less noise and reduce the distance where the creature can spot you. Room furniture and walls block its view, though it can navigate through the hotel halls.

The first version uses hand-drawn Canvas graphics and synthesized footsteps so it can run without downloads or external assets. It is a browser prototype rather than a finished Unity or Android release.
